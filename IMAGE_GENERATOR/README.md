# Monthly card image generators

These scripts render monthly announcement cards as JPEG files for the Ganapathi and Shiva chits.

- `generate_month_images.py`: Ganapathi cards for selected months.
- `generate_earlier_images.py`: earlier Ganapathi month cards/templates.
- `regenerate_shiva_images.py`: Shiva cards.

The scripts contain their own schedule/template data and currently use hard-coded `D:\CHIT` output paths. They render through a local Edge browser and use Pillow to convert screenshots to JPEG. Review the script's month list and output directory before running it; it may overwrite existing images. Ranganadh cards are generated by `TOOLS/excel_maintenance/create_ranganadh_chit.py` instead.

Current card dimensions vary by chit: Ganapathi cards are 1536×1024, while Shiva, Venkateshwara, and Ranganadh cards are 1024×731. These are the project files' existing formats, not a single shared output size.
